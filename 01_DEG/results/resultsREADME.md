# Results Inventory

This directory stores the outputs generated by the Paper 1 LUAD transcriptomic analysis scripts.

The GSE32863 expression assessment supports **Figure 2D** of the associated manuscript. Its outputs are organized within the analysis-specific `01_DEG/` directory, with separate subdirectories for figures, tables, statistical outputs, and audit reports.

## 1. GSE32863 Differential Expression Assessment

### 1.1 Figures

Directory: `results/01_DEG/figures/`

| File | Description |
|----|----|
| `Figure2D_GSE32863.pdf` | PDF version of Figure 2D |
| `Figure2D_GSE32863.tiff` | 600-dpi TIFF version of Figure 2D using LZW compression |

Figure 2D displays the expression distributions of *AOC3*, *MS4A7*, and *IL7R* in 57 matched tumor–normal pairs.

The figure is generated by:

`scripts/01_DEG/GitHub1_Paper1_differential_expression_GSE32863.R`

### 1.2 Tables

Directory: `results/01_DEG/tables/`

| File | Description |
|----|----|
| `GSE32863_target_gene_candidate_probes.csv` | Annotated candidate probes for the three target genes, including mean expression across the 116 samples |
| `GSE32863_selected_probe_per_gene.csv` | Selected probe record for each target gene, based on the highest mean expression across all 116 samples |
| `GSE32863_selected_gene_expression_all_samples.csv` | Selected-probe expression values and sample metadata for all 116 samples |
| `GSE32863_paired_expression_long_format.csv` | Long-format expression data for the 57 complete tumor–normal pairs |

These tables are generated by the Figure 2D expression-analysis script.

### 1.3 Statistical Outputs

Directory: `results/01_DEG/statistical_outputs/`

| File | Description |
|----|----|
| `GSE32863_probe_annotation_match_audit.csv` | Probe-annotation matching summary, including unmatched probes and annotation status |
| `GSE32863_paired_Wilcoxon_results.csv` | Paired Wilcoxon signed-rank test results and associated expression summaries for the three target genes |
| `GSE32863_analysis_summary.csv` | Summary of the cohort, sample numbers, probe-selection strategy, and statistical methods |
| `GSE32863_package_versions.csv` | Versions of the principal R packages used in the expression analysis |

The paired statistical analysis uses two-sided Wilcoxon signed-rank tests on the 57 complete tumor–normal pairs. Figure annotations display unadjusted P values. Any adjusted P values included in the statistical table should be interpreted according to the correction method recorded in that output.

### 1.4 Audit Reports

Directory: `results/01_DEG/audit_reports/`

The following reports are generated by:

`scripts/01_DEG/GitHub1A_GSE32863_Sample_Manifest_Export.R`

| File | Description |
|----|----|
| `GSE32863_sample_manifest_audit_summary.csv` | Summary of the GSE32863 cohort composition, including total samples, tissue groups, unique subjects, complete pairs, and singleton samples |
| `GSE32863_cross_file_sample_ID_audit.csv` | Cross-file consistency checks verifying GEO sample IDs, tissue-group assignments, singleton records, and complete coverage of the 116-sample cohort |

The sample-manifest audit summary confirms the following cohort structure:

- 116 samples in total;
- 58 tumor samples and 58 adjacent-normal samples;
- 59 unique subjects;
- 57 complete tumor–normal pairs;
- 114 samples included in paired analysis;
- two singleton samples: one tumor-only and one normal-only.

The cross-file audit report documents whether the sample IDs in the complete manifest, paired manifest, and singleton manifest are mutually consistent.

## 4. Interpretation

All numerical results should be interpreted from the generated output files rather than inferred from this inventory.

The expression comparisons describe tumor–normal differences within the GSE32863 cohort. They do not establish causal mechanisms or clinical diagnostic performance.

In addition to the R-based differential expression analyses and related downstream workflows, selected figures in this module were generated using the Xiantao Academic platform.

These exported figures are archived in the `Online_Tool_Generated/` directory. They document the visual outputs used in the manuscript and are maintained separately from figures generated directly by the R scripts.

### 3. Reproducibility and Provenance

The files listed above were exported from the Xiantao Academic platform and were not generated directly by the R scripts in this module.

The R-based analyses and online-platform visualizations are documented separately to distinguish their respective analytical and visualization workflows.

Where available, the original input data, analysis options, exported statistical results, and platform records should be retained to support result verification.

Exact reproduction of these visualizations may depend on the platform's available functions, software updates, default settings, and the original input data and analysis parameters.

### 4. Manuscript Correspondence

The exported figures are associated with Figure 2A–C in the current manuscript crosswalk.

The project-level `documentation/Figure_Table_Crosswalk.xlsx` and `documentation/External_Online_Analysis_Inventory.md` provide the corresponding manuscript mapping and external-platform output inventory.

The internal exported filenames are retained as stable analysis records. Their names are not required to match the final manuscript figure numbering.
