# Results — Immune Checkpoint Association and Sensitivity Analyses

## 1. Overview

This directory documents the results generated by the two R scripts for the immune checkpoint association and sensitivity analyses in lung adenocarcinoma (LUAD).

The analysis evaluates the associations between three prioritized study genes (**AOC3, MS4A7, and IL7R**) and 18 predefined immune checkpoint-related genes using TCGA-LUAD bulk-tumor transcriptomic data.

The predefined analysis consists of 54 gene-pair associations (3 core genes × 18 immune checkpoint-related genes), evaluated through three analytical layers:

1. Unadjusted Spearman rank correlations.
2. ImmuneScore-adjusted partial Spearman correlations.
3. TumorPurity-adjusted partial Spearman correlations.

A leave-one-core-gene-out audit further evaluates the dependence of the locked association patterns on the inclusion of individual core genes.

The primary analysis cohort contains 503 samples with the required expression and adjustment-variable data. All three association-analysis layers use the same 54 predefined gene pairs and target 503 samples per association.

This directory documents the expected result structures, locked numerical reference values, output files, and quality-control procedures. Runtime PASS/FAIL status should be reported only after inspection of the corresponding execution logs and generated files.

## 4. Primary Immune Checkpoint Association Results

### 4.1. Unadjusted Spearman associations — STEP 8C-4

Two-sided Spearman rank-correlation tests are performed for all 54 predefined core-gene/checkpoint-gene pairs.

P values are adjusted across the 54 comparisons using the Benjamini–Hochberg (BH) procedure.

The result table contains:

- Core gene.
- Immune checkpoint-related gene.
- Number of complete sample pairs.
- Spearman correlation coefficient.
- Nominal P value.
- BH-adjusted FDR.
- Association direction.

The expected analysis structure is:

| Metric | Expected value |
|---|---:|
| Core genes | 3 |
| Checkpoint-related genes | 18 |
| Total associations | 54 |
| Samples per association | 503 |

Expected output:

`Workflow-08-STEP8C4_core_checkpoint_Spearman_54tests.rds`

### 4.2. ImmuneScore-adjusted partial Spearman associations — STEP 8C-5A

Partial Spearman correlations are calculated using a rank-based residual procedure:

1. Rank the expression values of each variable and the ImmuneScore.
2. Regress each ranked expression variable on the ranked ImmuneScore.
3. Calculate the Pearson correlation between the residuals for each gene pair.
4. Apply BH correction across the 54 comparisons.

The expected result structure contains:

- 54 predefined gene-pair associations.
- 503 samples per association.
- Partial Spearman correlation coefficients.
- Nominal P values.
- BH-adjusted FDR values.
- Association directions.
- ImmuneScore as the adjustment variable.

Expected output:

`Workflow-08-STEP8C5_core_checkpoint_partialSpearman_ImmuneScore_54tests.rds`

### 6.2. Tumor-purity derivation

Tumor purity is derived from the ESTIMATE score using:

\[
\mathrm{TumorPurity}
=
\cos\left(
0.6049872018+
0.0001467884\times\mathrm{ESTIMATEScore}
\right)
\]

The previously saved ESTIMATE scores are restored rather than recalculated.

## 8. Interpretation and Limitations

The three analytical layers characterize statistical associations between bulk-tumor gene-expression measurements.

The observed results indicate that the association patterns are sensitive to the adjustment strategy:

- 48 of 54 associations are FDR-significant in the unadjusted analysis.
- 38 of 54 remain FDR-significant after ImmuneScore adjustment.
- 39 of 54 are FDR-significant after TumorPurity adjustment.
- 27 of 54 are significant across all three analytical layers.

The direction-transition patterns also demonstrate that the associations are not uniformly consistent across adjustment strategies.

These results should not be interpreted as evidence of:

- Direct molecular interactions.
- Direct checkpoint regulation by AOC3, MS4A7, or IL7R.
- Cell-intrinsic regulatory activity.
- Causal or mechanistic reversal.
- Functional immune effects.
- Clinical diagnostic performance or therapeutic response.

Bulk-tumor expression reflects a mixture of cellular populations and biological states. Adjustment for ImmuneScore or estimated TumorPurity does not eliminate all potential confounding by cellular composition.

The leave-one-core-gene-out audit assesses dependence on the composition of the predefined gene-pair set. It does not constitute independent replication or a new set of statistical tests.
