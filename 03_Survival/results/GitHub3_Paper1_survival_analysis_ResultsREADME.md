# Survival Analysis Results

## 1. Overview

This directory stores the statistical results, analysis checkpoints, audit reports, tables, and figures generated by the survival analysis workflow in the Paper 1 LUAD study.

**Study:**\
Integrated transcriptomic and single-cell characterization of AOC3, MS4A7, and IL7R in LUAD

The survival analysis results are organized into four major components:

| Analysis component | Main script | Primary outputs |
|----|----|----|
| STEP 6B | `GitHub3_Paper1_survival_analysis_1.R` | Continuous univariable Cox results, PH diagnostics, and MS4A7 time-varying Cox checkpoints |
| STEP 6C | `GitHub3_Paper1_survival_analysis_2.R` | Clinical covariate audits, multivariable Cox results, and adjusted MS4A7 time-varying Cox checkpoint |
| STEP 6D / STEP 6X | `GitHub3_Paper1_survival_analysis_3.R` | Three-gene Cox reporting tables, Figure 4, genome-wide Cox results, and Figure X |
| STEP 6E | `GitHub3_Paper1_survival_analysis_4.R` | Survival cohort audits, median-split group assignments, Kaplan–Meier curves, log-rank results, and grouped Cox results |

## 3. STEP 6B — Continuous Univariable Cox and MS4A7 Time-Varying Analysis

### 3.1 Continuous Univariable Cox Regression

Each prioritized study gene is evaluated separately using continuous Z-score-standardized expression.

The analysis reports:

- Hazard ratios per one-standard-deviation increase in expression.
- 95% confidence intervals.
- Nominal P values.
- Schoenfeld residual-based proportional-hazards test results.

The Cox models use Efron tie handling.

### 3.2 MS4A7 Time-Varying Cox Analysis

The time-varying effect of MS4A7 is evaluated using three prespecified time functions:

| Candidate function | Time transformation |
|--------------------|---------------------|
| Linear             | `t`                 |
| Square-root        | `sqrt(t)`           |
| Logarithmic        | `log1p(t)`          |

Candidate models are compared using AIC. The selected time-varying model is compared with the constant-coefficient MS4A7 Cox model using a likelihood-ratio test.

Time-specific hazard ratios and 95% confidence intervals are estimated at:

- 1 year
- 2 years
- 3 years
- 4 years
- 5 years

The selected time function, model coefficients, comparison statistics, and time-specific estimates should be taken from the saved analysis objects and verified execution outputs.

## 9. Result and Checkpoint Verification

The following distinctions must be maintained when interpreting the results directory:

1.  A checkpoint file records the objects saved by the script; its presence does not automatically establish that all QC checks passed.
2.  The STEP 6B-6 / STEP 6B-7 checkpoint object list should be checked against `step6b7_objects` in the complete script.
3.  The STEP 6C-5 checkpoint preserves previously fitted model objects. The supplementary `p_lrt_from_locked_LR` object is calculated after saving and is not included in the saved object list.
4.  The STEP 6X-8E-final checkpoint should be inspected because the described second core-gene annotation correction is not followed by another save operation.
5.  `audit_6X9A` is an in-memory audit object, not a separately saved file.
6.  The STEP 6X-9B checkpoint may be saved even if `step6X9B_pass` is FALSE. The QC flag must be checked independently.
7.  The STEP 6X-9C-R4 checkpoint stores visual-refinement objects and figure export paths, not newly fitted survival models.
8.  Figure 4 and Figure X are separate outputs generated by different analysis components.
9.  STEP 6E grouped Cox HR estimates represent median-defined High-versus-Low comparisons and must not be confused with continuous-expression Cox estimates.
10. Expected QC counts and programmed output filenames should not be described as confirmed results until checked against actual execution records.
