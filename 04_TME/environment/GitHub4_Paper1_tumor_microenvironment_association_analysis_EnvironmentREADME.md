# Computational Environment and Dependencies

**Study:** Integrated transcriptomic and single-cell characterization of AOC3, MS4A7, and IL7R in LUAD

## 1. Overview

This directory documents the R software environment, package dependencies, computational functions, upstream data requirements, and reproducibility considerations for the Paper 1 tumor microenvironment (TME) analysis.

The TME workflow consists of three analysis scripts:

- `GitHub4_Paper1_tumor_microenvironment_association_analysis_1.R`
- `GitHub4_Paper1_tumor_microenvironment_association_analysis_2.R`
- `Supplementary_Table_ABSOLUTE_Purity_Adjusted_Regression.R`

The first script performs gene–TME association analysis, manuscript-ready table and figure generation, ABSOLUTE tumor-purity source auditing, purity-adjusted regression, historical ESTIMATE object inspection, and ESTIMATE signature-membership auditing.

The second script reconstructs and validates original ESTIMATE scores, evaluates the official ESTIMATE implementation and signature-object integrity, and performs formal leave-one-gene-out (LOO) sensitivity analyses for AOC3 and IL7R.

The third script independently extracts and audits the archived ABSOLUTE purity-adjusted regression results generated by the upstream STEP7B5 and STEP7B6 workflows. It verifies the locked dataset, retrieves coefficients from the previously fitted models, recalculates the Benjamini–Hochberg (BH) adjustment for the nine gene-level P values, compares the extracted results with the archived results, and generates Supplementary Table 3a and supporting audit files.

The third script does not refit the regression models, repeat sample matching, or replace the original gene–TME correlation analysis.

The workflow primarily uses base R and selected CRAN packages. It reuses previously generated and locked WGCNA, ESTIMATE, and ABSOLUTE data products rather than independently repeating all upstream analyses.

This README summarizes the combined environment requirements of all three scripts. Exact software versions, package installation status, input availability, and successful execution must be confirmed from the corresponding runtime records.

## 6. Statistical Analysis Environment

### 6.1 Gene–TME Association Analysis

The first script evaluates three prioritized study genes against three ESTIMATE-derived TME traits.

The analysis includes nine prespecified comparisons:

- AOC3, MS4A7, and IL7R.
- StromalScore, ImmuneScore, and ESTIMATEScore.

Statistical settings:

| Parameter                      | Setting            |
|--------------------------------|--------------------|
| Correlation method             | Spearman           |
| Exact calculation              | `exact = FALSE`    |
| Number of comparisons          | 9                  |
| Multiple-testing correction    | Benjamini–Hochberg |
| Nominal significance threshold | P \< 0.05          |
| FDR significance threshold     | BH-FDR \< 0.05     |
| Expected primary TME cohort    | 513 samples        |
| Random seed                    | Not applicable     |

The manuscript-ready table and figure use previously generated association results. Formatting, export, and read-back checks do not constitute additional gene–TME statistical tests.

### 6.2 ABSOLUTE Purity-adjusted Linear Regression

The original purity-adjusted analysis uses ordinary least-squares linear regression implemented with base R.

The model specification is:

``` r
TME trait ~ Study gene + ABSOLUTE_Purity
```

The workflow includes nine prespecified models, corresponding to three study genes and three ESTIMATE-derived TME traits.

Benjamini–Hochberg correction is applied across the nine gene-level P values.

The expected sample size is approximately 500, depending on the availability of usable ABSOLUTE purity measurements and successful sample matching. The actual model sample sizes must be confirmed from the fitted models and execution results.

Model validation and coefficient extraction from existing fitted models should not be interpreted as additional model fitting.

All associations are observational and should not be interpreted as evidence of causality.

### 6.3 ESTIMATE Score Reconstruction and LOO Sensitivity Analysis

The second script performs two related but distinct computational tasks:

1.  Reconstruction and validation of original ESTIMATE scores.
2.  Formal AOC3-LOO and IL7R-LOO score calculation.

The official ESTIMATE functions are:

- `filterCommonGenes()`
- `estimateScore()`

The implementation-based reconstruction also uses base R functions such as `rank()`, `order()`, and `cumsum()`.

Numerical comparison metrics include:

- Pearson correlation.
- Spearman correlation.
- Maximum absolute difference.
- Mean absolute difference.
- Root mean squared error (RMSE).

The script-defined reconstruction criteria include Pearson and Spearman correlations greater than 0.999999999 and maximum absolute difference below 1e-8.

These are predefined validation criteria, not evidence of successful reconstruction unless confirmed by the corresponding execution records.

The formal LOO analyses use separate reduced signature definitions:

| LOO target | Signature modification                         |
|------------|------------------------------------------------|
| AOC3-LOO   | Remove AOC3 from the original StromalSignature |
| IL7R-LOO   | Remove IL7R from the original ImmuneSignature  |

MS4A7 is not included in either original ESTIMATE signature and is therefore not a signature-specific LOO target.

The LOO analyses compare reconstructed scores with the locked original Step14 reference and evaluate gene-expression–LOO-score associations.

Signature substitution and restoration checks are important because the actual symbol-resolution behavior of the installed ESTIMATE implementation affects whether the intended reduced signature is used by `estimateScore()`.

### 6.4 Archived ABSOLUTE Purity-adjusted Regression Result Extraction

The standalone extraction script retrieves and audits the previously fitted ordinary least-squares regression models stored in the STEP7B6 checkpoint.

The archived model specification is:

``` r
TME trait ~ Study gene + ABSOLUTE_Purity
```

The nine model combinations comprise:

- Three prioritized study genes: AOC3, MS4A7, and IL7R.
- Three TME traits: ImmuneScore, StromalScore, and ESTIMATEScore.

The extraction workflow includes:

1.  Loading the locked STEP7B5 dataset and STEP7B6 regression checkpoint.
2.  Verifying the required archived objects and their structures.
3.  Checking the expected dataset size, sample identifiers, and analysis-variable completeness.
4.  Extracting the study-gene and ABSOLUTE-purity coefficients from the archived fitted models.
5.  Recording model observation counts and coefficient-level statistics.
6.  Recalculating BH-adjusted P values across the nine gene-term P values.
7.  Comparing the recalculated results with the archived `Gene_FDR_BH` values.
8.  Exporting Supplementary Table 3a and supporting audit files.

The script uses functions such as `summary()`, `coef()`, `nobs()`, and `p.adjust()` to extract and verify model results. It does not call `lm()` to refit the archived regression models.

The expected dataset size is 500 samples, and the expected number of archived models is nine. These are script-defined validation targets rather than independent confirmation of successful execution.

The final audit includes checks of model availability, model observation counts, coefficient extraction, and agreement between recalculated and archived BH-adjusted results.

The script also defines a strict final audit condition requiring all nine gene-term BH-adjusted P values to be below 0.05. This condition should be reported as a script-defined criterion, not as an observed result unless the final audit report confirms it.

The extracted coefficients represent observational associations conditional on ABSOLUTE tumor purity. They should not be interpreted as causal effects.
