# Results — Tumor-Only WGCNA

## 1. Overview

This directory stores the results generated by the tumor-only weighted gene co-expression network analysis (WGCNA) workflow for the Paper 1 LUAD study.

The analysis is based on 513 primary LUAD tumor samples and integrates gene co-expression modules with clinical characteristics, overall-survival outcomes, and tumor microenvironment (TME)-related scores.

The results are organized into six main analytical stages:

1.  Cohort reconstruction, expression preprocessing, and pre-WGCNA quality control.
2.  WGCNA network construction, module identification, and clinical/survival association analyses.
3.  Time-dependent Cox analyses of the brown module and selected clinical variables.
4.  ESTIMATE-based TME scoring and module-level TME association analyses.
5.  Gene-level GS/MM integration, candidate-gene mapping audits, and workspace archiving.
6.  Supplementary figure and table preparation and final workspace recovery.

This README serves as a high-level result index. It highlights the principal output directories, key result files, figures, tables, and reproducibility records. It does not reproduce the complete inventory of intermediate files generated by each workflow.

**Important:** The file names and directory locations below describe the output organization documented by the corresponding analysis scripts and workflow-specific README files. Actual file availability and integrity must be confirmed in the project directory after successful execution.

### 3.4 Interpretation and data-integrity notes

The expected cohort contains 513 Primary Tumor samples. The expression-prevalence criterion retains genes with raw FPKM-UQ values strictly greater than 1 in at least 103 samples, followed by:

$$\log_2(\mathrm{FPKM\text{-}UQ}+1)$$

MAD-positive gene selection is documented separately from expression-prevalence filtering.

PCA, hierarchical clustering, sample connectivity, and TSS-level summaries are descriptive QC analyses. They are not independent criteria for automatic sample exclusion.

Historical gene and sample counts are reference values. Final data-integrity conclusions should be based on the generated manifests, summaries, and audit files.

**Workflow boundary:** Workflow-04-2D performs pre-analysis QC only. WGCNA network construction begins in the subsequent workflow.

### 7.4 Interpretation

The following measures represent distinct analytical levels and should not be conflated:

- **Gene-level GS:** association between individual gene expression and a TME-related trait.
- **Module-level TME association:** association between a module eigengene and a TME-related score.
- **Gene-level MM:** correlation between an individual gene and its assigned module eigengene.
- **Within-module MM–GS association:** relationship between module membership and gene significance within a module.

Descriptive integration tables are not additional independent statistical tests.

The actual presence of the listed files depends on successful execution of the corresponding export statements.

## 11. Reproducibility and Interpretation Principles

The following principles apply across the tumor-only WGCNA result directories.

1.  **Cohort preservation:** The expected tumor-only cohort contains 513 primary LUAD tumor samples. Sample IDs and their original expression-matrix order should be preserved unless a separately justified and documented change is made.

2.  **Audit-based verification:** Expected sample counts, gene counts, module counts, and validation values are reference information. Actual results must be confirmed from the generated output files.

3.  **Expression filtering and annotation are separate:** Gene annotation availability and gene biotype do not determine expression retention in the prevalence-filtering workflow.

4.  **MAD and variance are distinct:** MAD = 0 does not necessarily imply variance = 0. The MAD-based gene set is documented separately from the initial expression-prevalence filter.

5.  **Preservation of locked results:** Downstream integration workflows should use the previously generated and locked WGCNA, MM, GS, and TME results unless a new analysis is explicitly specified and documented.

6.  **No unsupported causal interpretation:** Module–trait correlations, gene-level GS, MM–GS relationships, and time-dependent Cox estimates describe statistical associations. They do not independently establish causal mechanisms or clinical validity.

7.  **Distinction between in-memory and exported results:** Objects printed to the console or created only in memory should not be described as saved result files unless an explicit export operation has been executed.

8.  **Checkpoint integrity:** RData/RDS checkpoints, session information, object inventories, and archive manifests should be retained alongside the relevant analysis outputs.

9.  **File-generation verification:** A file listed in an analysis README represents an intended or script-defined output. It should be treated as an available result only after its existence and integrity have been confirmed.

10. **Version and overwrite awareness:** Historical output files may be overwritten when different script versions use the same filenames. Preserve required versions and document the source script associated with each locked result.
