# Single-Cell Analysis Results

## 1. Overview

This directory stores the results generated by the Paper 1 single-cell transcriptomic characterization workflows.

The analysis is implemented in two R scripts:

- `GitHub7_Paper1_Single_Cell_Analysis_1.R`
- `GitHub7_Paper1_Single_Cell_Analysis_2.R`

The workflows characterize the prioritized study genes **AOC3, MS4A7, and IL7R** using the TISCH2 `NSCLC_GSE131907` dataset and patient-level compartment-specific raw-UMI pseudobulk data.

The results include cell-type visualization, patient/sample structure audits, compartment cell-count feasibility assessments, raw-count matrix and cell-ID reconciliation, patient-level pseudobulk construction, descriptive expression profiling, evidence synthesis, and manuscript supplementary exports.

The README distinguishes between:

1. Output files identified in the uploaded script documentation.
2. In-memory analysis objects that are not shown as exported files.
3. Expected output files whose actual generation requires execution-time verification.

No numerical results are presented as independently verified unless supported by the corresponding executed output files.

Detection is defined as raw UMI count greater than zero. Zero-count observations are retained and are not automatically treated as missing values or grounds for patient exclusion.

The STEP10D–STEP10H workflows described here are primarily intended for descriptive expression characterization, structural validation, evidence integration, and manuscript-oriented reporting.
